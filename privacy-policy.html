Privacy Policy for SpectraLens AI

Effective Date: August 21, 2026
Last Updated: August 21, 2026

1. Single Purpose & Overview

SpectraLens AI is an in-browser productivity and research companion designed to assist users with simultaneous multi-engine AI querying (ChatGPT, Claude, Gemini, Grok, Perplexity, Google Search), visual DOM element extraction, and on-device Optical Character Recognition (OCR) directly within active web pages.

2. Zero Data Collection & No External Telemetry

  • No Remote Data Logging: SpectraLens AI does NOT collect, track, store, sell, or transmit any personally identifiable information, browsing history, keystrokes, or clipboard contents to any external developer servers or analytics networks.
  • Zero Analytics SDKs: The extension contains zero tracking pixels, zero analytics scripts (no Google Analytics, Sentry, Mixpanel, or PostHog), and zero advertising trackers.
  • Direct Browser Transport: All queries travel directly between your browser and the official AI provider (OpenAI, Anthropic, Google, xAI, Perplexity). Zero intermediary or proxy servers intercept or store your requests.
  • No Accounts Required: You do not need to register or provide personal credentials to use SpectraLens AI.

3. 100% On-Device Local Data Storage

  • Isolated Sandbox: User preferences (theme mode, model priority, copy rules) and conversation logs are stored strictly inside your browser's private LevelDB storage partition via Chrome's sandboxed chrome.storage.local API.
  • Data Portability: You can export your entire conversation history at any time as structured JSON (`.json`) or formatted Markdown (`.md`) for Obsidian or Notion.
  • One-Click Total Data Erasure: You can clear individual sessions, wipe all chat logs, or perform a full factory reset at any time with a single click.

4. Visual Element Scanner & On-Device OCR

  • Targeted DOM Extraction: The Visual Element Scanner only reads HTML elements you explicitly click on. It never monitors keystrokes or background page contents.
  • Offline WebAssembly OCR: Screen capture regions are processed in-memory using a bundled, offline Tesseract.js WebAssembly engine in a sandboxed offscreen document. Images are transient in memory and are never uploaded to remote servers.

5. Manifest V3 Permissions Justification

storage

Persists user preferences, domain rules, and chat history locally on your device.

activeTab

Interacts with active tab on user invocation (popup, floating widget, shortcuts).

scripting

Injects visual element selector overlay, copy unblocker styles, and extracts answers.

offscreen

Runs offline Tesseract OCR in a sandboxed background document without blocking UI.

tabs

Creates and cleans up background query tabs to stream responses from AI providers.

declarativeNetRequest

Blocks heavy images/media on background query tabs to save user bandwidth.

6. Chrome Web Store Limited Use Compliance

SpectraLens AI complies fully with the Chrome Web Store User Data Policy, including all Limited Use requirements. User data is never transferred to third parties for advertising, credit scoring, or data brokering.
