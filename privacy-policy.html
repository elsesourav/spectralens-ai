Privacy Policy for SpectraLens AI

Effective Date: August 15, 2026
Last Updated: August 15, 2026

1. Single Purpose & Overview

SpectraLens AI is an in-browser productivity companion designed to assist users with research, Optical Character Recognition (OCR), and multi-engine AI answer aggregation (Google AI Overview, Bing/Copilot, Perplexity, Gemini, Grok) directly within web browsing workflows.

2. Zero Data Collection & No External Telemetry

  • No Data Collection: SpectraLens AI does NOT collect, store, track, sell, or transmit any personally identifiable information, browsing history, keystrokes, or clipboard data to any developer servers or analytics networks.
  • Direct-to-Engine Processing: Search queries initiated by the user are communicated directly from the user's browser to the designated search provider (Google, Bing, Perplexity, Gemini, Grok) without intermediary proxies.
  • No Accounts Required: The extension operates anonymously without account registration or sign-in.

3. Local Device Storage

  • Local Storage Only: User preferences (enabled AI engines, theme, concurrency) and recent query history (up to 20 entries) are stored strictly within the user's local browser using Chrome's chrome.storage.local API.
  • Instant History Clearing: Users can purge all local search history at any time with a single click.

4. Screen Capture & On-Device OCR

  • Local Processing: Screen captures for Area OCR are processed in memory on your local device using an offline, locally-bundled WebAssembly Tesseract.js engine.
  • Zero Image Retention: Bitmaps are held transiently in local browser memory and immediately discarded upon text extraction. Images are never uploaded or retained.

5. Minimum Necessary Permissions

  • storage: Retains your preferences and chat history locally.
  • activeTab & scripting: Injects the floating menu and area crop tool on the active page upon user request.
  • offscreen: Runs sandboxed offline OCR in the background.
  • tabs: Manages background query tabs to fetch answers from enabled providers.
  • declarativeNetRequest: Blocks media/fonts on scraping tabs to conserve bandwidth.

6. Chrome Web Store Limited Use Compliance

SpectraLens AI strictly complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. We do not transfer or use user data for personalized advertising, credit assessment, or data brokering.
